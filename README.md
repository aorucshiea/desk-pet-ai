# Desk Pet AI

A local-first desktop pet AI. (work in progress)

The brain is a local Python gateway shared by two shell versions:

| Version | Path | Installer size | Status |
| --- | --- | --- | --- |
| **Electron (original)** | [`clawd-on-desk/`](./clawd-on-desk) | ~770 MB | Full feature set |
| **Tauri (rewrite)** | [`deskpt-tauri/`](./deskpt-tauri) | ~10.7 MB | High-fidelity replica; parity in progress |

Git tags: `v0.10.0-electron` marks the original Electron shell; `v0.1.0-tauri` marks the first Tauri rewrite.
