# Desk Pet AI

本地优先的桌面宠物 AI。（开发中）

大脑是本地 Python 网关，两个外壳版本共用：

| 版本 | 路径 | 安装包体积 | 状态 |
| --- | --- | --- | --- |
| **Electron 版（原版）** | [`clawd-on-desk/`](./clawd-on-desk) | ~770 MB | 功能完整 |
| **Tauri 版（重写）** | [`deskpt-tauri/`](./deskpt-tauri) | ~10.7 MB | 高保真复刻，功能补齐中 |

Git 标签：`v0.10.0-electron` 标记原 Electron 壳；`v0.1.0-tauri` 标记首个 Tauri 重写版。
