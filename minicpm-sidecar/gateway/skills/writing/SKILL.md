# 简洁写作技能

## 写作原则

1. **一句话一个想法**：每句话只表达一个核心概念
2. **删掉多余的词**："really", "very", "actually", "basically" 几乎永远是多余的
3. **用动词代替名词**："make a decision" → "decide", "give assistance" → "help"
4. **主动语态**："The file was read by the program" → "The program reads the file"

## 技术写作检查清单

| 问题 | 说明 |
|------|------|
| 开头直击要点 | 第一句告诉读者"这是什么"和"为什么重要" |
| 段落 < 5 句 | 长段落让读者失去注意力 |
| 术语有定义 | 首次出现的专业术语给出简短解释 |
| 步骤编号 | 给操作步骤编号，而非用段落描述 |

## 例子

### 不好
"The way that the configuration file is being processed by the application is something that could really benefit from a performance optimization in the future."

### 好
"Optimize configuration file processing. The current approach reads the file three times."
