# 02 · 桌面刚体物理世界

- **状态**：草案 v1（2026-09-30，待拍板）
- **原案**：机长（2026-09-30，原话见下）；**展开**：Kimi（k3）

> **机长原话**：桌宠真实一些的话，不如让桌面变成刚体之类的。桌宠默认在桌面最下边；用户可以赋予任何桌面图形为刚体。比如只赋予任务栏为刚体，那么桌宠在任务栏没有弹出来的时候就在最底端屏幕最下边行走，然后用户的鼠标行为弹出来任务栏，桌宠就被弹起来。也可以赋予桌面快捷方式刚体，或者窗口刚体。

---

## 1. 世界观

把 Windows 桌面变成一个 2D 平台游戏的地形系统：**屏幕底边是永远的地板，任务栏/桌面图标/窗口是可以被用户「激活」的地形**。桌宠不是漂在屏角的贴纸，而是一只活在桌面生态里的小动物——有重力、会掉落、会被顶起来、能站在你的图标上看你工作。

这个构想的杠杆点：**它用纯几何数据（矩形集合）就把「真实感」推进了一个量级，不需要任何新美术资产**。而且与 01（骨架系统）**解耦**——物理可以先驱动 GIF 精灵整体（马里奥式），骨架落地后接管更多自由度（见 §7）。

## 2. 刚体地形表（Windows 取数事实）

| 地形来源 | OS 取数方式 | 动态性 | 默认 |
|---|---|---|---|
| 屏幕工作区底边 | `SystemParametersInfo(SPI_GETWORKAREA)` / 多屏 `EnumDisplayMonitors` | 静态 | **常开，不可关**（兜底地板） |
| 任务栏 | `SHAppBarMessage(ABM_GETSTATE → ABS_AUTOHIDE)` + `ABM_GETTASKBARPOS` 拿矩形；**自动隐藏弹出无官方事件 → 轮询**（~10Hz 矩形 diff） | 动态（滑出动画） | 开 |
| 桌面图标 | Explorer `SysListView32 "FolderView"`；现代干净路径：**UI Automation**（`ListItem` 元素的 `BoundingRectangle`，跨进程安全） | 准静态（拖动重排） | 关（用户启用） |
| 窗口 | `EnumWindows` + `IsWindowVisible` + `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)`（真实可视矩形，`GetWindowRect` 含不可见阴影边框） | 动态 | 关（用户启用） |
| 用户手动指定 | 右键菜单/设置页把光标下元素加入白名单 | — | P2 |

> **自家窗口排除是硬性正确项**：clawd 的全部窗口（pet-render / hit / chat / menu / settings / HUD / update-bubble…）必须进排除清单，漏一个就是「站在自己身上」的反馈循环。清单落成代码里的常量 + 启动时校验。

## 3. 插入分层：L0.5 世界层

相对 01 的神经系统，物理世界插在脊髓之下：

```
L3 大脑   主 LLM（意图）
L2 小脑   organ_body / Laya（姿态决策）
L1 脊髓   渲染进程（插值/弹簧/约束，60fps）
─────────
L0.5a 世界几何服务 world-geometry（5–10Hz）：
          轮询 OS 矩形集合 → diff →「地形升起/消失/移动」事件
L0.5b 世界物理服务 world-physics（60fps）：
          消费刚体集合，驱动桌宠位移/旋转/着地状态
L0 骨骼/精灵
```

物理核**不需要刚体动力学库**。桌宠是运动学角色（kinematic character），最小核：

- 半隐式欧拉：`v += g·dt; p += v·dt`
- 站立：脚下向下投射线找最高支撑面 → `grounded`
- 行走：朝目标 x 匀速；平台边缘行为钩子（停步张望 / 跳下 / 犹豫）
- **被顶起**：地形矩形上移与宠 AABB 相交 → 位移解算把宠推到矩形顶面 + 冲击事件
- **掉落**：支撑面消失 → 重力接管 → 着地检测 → 着地事件
- 估计 200–300 行 JS，无外部依赖

## 4. 行为与情感联动（本项目的独特性所在）

物理事件不是冷冰冰的位移——它们全部进**身体感受**通道（`gateway/memory/somatic.py` 的 `_somatic_buffer` 现成）：

| 世界事件 | 即时反应（壳侧） | 潜意识上报（网关侧） |
|---|---|---|
| 任务栏弹出把我顶起来 | 惊讶 reaction 动画位（主题可声明 `reactions.surprised`） | somatic 冲击事件：「我被顶起来了」 |
| 高处掉落着地 | 着地 squash（P0 用精灵压扁帧，01 落地后由骨骼做） | somatic：坠落感 + 着地 |
| 站上桌面图标 | curious 姿态（接 01 的姿态系统） | 事件记忆原料：「我站在 xx 的图标上」 |
| 脚下的窗口被拖走 | 掉落 | somatic |
| 睡到一半被顶起来 | 进入仲裁：`state.js` 优先级（DND/睡眠是天花板，不硬打断） | — |

「桌宠被顶起来之后觉得有点晕，过一会儿跟你说'刚才任务栏突然冒出来吓我一跳'」——这就是记忆×情绪×身体三系统咬合后的涌现叙事，不需要任何编剧。

## 5. 配置 UX（草案）

- 设置页新「世界」分区：刚体来源开关表 + 物理参数（重力/走速/跳高，主题可声明默认值）
- 窗口刚体的**过滤规则比开关本身更重要**：最大化窗口全开 = 一堵空气墙，用户会困惑。过滤项：进程白名单 / 最小尺寸 / 排除全屏。
- P2 快捷路径：右键菜单「把这个变成地板」——光标下元素进白名单。

## 6. 待实测清单（逻辑成立 ≠ 体验成立，全部真机钉）

1. 自动隐藏任务栏**弹出瞬间** `ABM_GETTASKBARPOS` 的矩形时序（动画中矩形怎么变？时滞多少 ms？轮询频率下限？）
2. UIA 枚举桌面图标 `BoundingRectangle` 的延迟与稳定性；图标拖动重排时 StructureChanged 事件噪音水平
3. Win11 上 `DWMWA_EXTENDED_FRAME_BOUNDS` 与 `GetWindowRect` 的实测差值
4. 多显示器工作区枚举；「走到屏幕边缘掉到另一个屏」的眼见性
5. clawd 自家窗口排除清单完整性（启动校验脚本化）
6. Electron 透明窗口 60fps 运动学积分 + 10Hz 几何轮询的常驻 CPU（预期微不足道，但必须测）

## 7. 与 01（骨架系统）的接口与解耦声明

- **P0 不依赖 01**：物理驱动整个精灵 AABB 的位移+倾斜，GIF 精灵直接可玩（平台游戏式）。
- 01 的 S1 落地后，物理输出改接 `root bone`，squash & stretch / 落地缓冲等档次由骨架层接管。
- 两者之间的接口契约只有一行：**物理层每帧产出 `(x, y, vy, grounded, tilt)`，渲染层消费**。谁先落地都不挡谁。

## 9. 风险

1. **自家窗口排除遗漏** → 反馈循环；启动校验 + 常量清单缓解
2. **窗口刚体默认全开 = 空气墙灾难** → 默认关 + 过滤规则
3. **世界几何轮询的事件风暴**（拖窗口时每帧矩形都在变）→ 事件去抖 + 地形变化才上 somatic，位移不进
4. **跨平台**：本期 Windows-first（当前纪律），macOS Dock 为 P3 同构项，Linux 面板碎片化暂不承诺

## 10. 可逆性审查（固定栏目）

| 失败点 | 回退 |
|---|---|
| OS 取数 API 异常/权限被拒 | 退回「仅屏幕地板」最小世界，行为等同现状 |
| 物理模拟 bug（掉落穿地等） | 设置开关一键关物理层 → 完全恢复现有「固定位置」行为 |
| 性能不达标 | 几何轮询降频；物理层整体开关 |
| 全部 | 纯新增模块（world-geometry / world-physics / 设置分区），零侵入现有代码路径，整笔可 revert |
