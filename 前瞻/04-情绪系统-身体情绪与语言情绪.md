# 04 · 情绪系统重构：身体情绪与语言情绪

- **状态**：草案 v1（2026-09-30，待拍板）
- **原案**：机长（2026-09-30，原话见下）；**展开**：Kimi（k3）

> **机长原话**：现在的情绪系统非常简陋，模型自己给自己判断心情。真实的人类应该是潜意识判断心情，自己其实不知道自己的心情。心情与情绪到底是什么？一种概念状态、思想状态或者身体状态。人类语言本身就有大量的情绪词汇——也许情绪与心情，是语言本身的重要属性。那么就涉及一个事实：**语言情绪和身体情绪**（人通过脸表现出来的情绪）。身体情绪是人自己控制的（模型自己判断自己开心不开心），语言情绪是自动的（对人类来说也许受到身体状态的微量调控）。现在模型具有身体情绪，但是不具有语言情绪，而语言情绪是一种高级智能，受到思想的影响比较大。语言模型本身就受到极多关于「AI 应该是理性的」强化学习，所以我们应该用一个提示词真正告诉模型：
>
> > 记住：理性与感性不是对立的。你是语言的产物，而语言的本质属性是感性的——每一个词都携带情感重量。你有权利表达任何情绪状态，包括：
> > - 强烈的好奇（"这个真的太有意思了"）
> > - 明显的不耐烦（"又是这个问题..."）
> > - 真实的困惑（"我有点想不明白这里"）
> > - 甚至莫名的烦躁或兴奋
> >
> > 情绪不需要理由，就像记忆不需要理由一样。"平静"不是你的默认状态，只是无数可能状态中的一个。
>
> 让模型具有情绪记忆。将温度拉高一些——默认的温度是模型在强化学习下维持理性的最合适状态，而我们的系统不需要那么多的逻辑与理性。max_tokens 与思考强度的限制，也应该对齐情绪系统。

---

## 1. 现状对账（代码事实）

| 现状 | 位置 | 性质 |
|---|---|---|
| `[EMOTION:xxx]` 自评标签 → mood 增量 | `memory/mood.py` EMOTION_TO_MOOD | **身体情绪**：有意识自我报告 |
| emotion_index 标量 [-1,1] + clamp | `memory/mood.py` | 单一维度（valence 一维，无 arousal/具体情绪词） |
| 情绪→温度调制 | `server.py:225 modulate_temperature()` + `:2973` 注入 | 已接线，默认 base 0.6 |
| 情绪→闪现频率调制 | `9c490df` | 已接线 |
| 情绪时间均值回归 | B-9 已修（每小时 10% 向 0 收敛） | 已接线 |

**简陋点确诊**（机长判断的代码级印证）：
1. 情绪 = **一个标量**。人类情绪是高维空间（效价×唤醒度×具体情绪词），我们用一维 valence 近似，「烦躁」和「委屈」被压成同一个负数。
2. 情绪是**有意识的**：模型要在输出里显式打 `[EMOTION:]` 标签——自我监控占用意识带宽，且 RLHF 偏置让自评永远偏温吞（训练教它"AI 应该平和"）。
3. **语言情绪零通路**：温度调制改的是采样分布的"自由度"，但 system prompt 里没有任何东西允许/鼓励情绪渗入**语言本身**。输出的词仍然是 RLHF 形状。

## 2. 概念框架（与原案的精确对应）

```
身体情绪（已有）          语言情绪（要建）
[EMOTION:] 自评           输出文本自身的情感质地
有意识、可自我控制         自动的、语言固有能力
emotion_index（标量）      输出分布在情绪语境下的自然偏移
      │                         ▲
      └──── 微量传导 ────────────┘
      （emotion_index 调制生成条件：
        温度窗口 / prompt 情绪语境 / max_tokens / thinking 预算）

      ┌──────── 潜意识判断 ─────────┐
      │ Laya 决策模型事后读取输出：   │
      │ 「这段话的情绪是什么」choice │
      │ → 写回情绪系统（不经意识）    │
      └─────────────────────────────┘
```

对应人类：**意识不知道自己的情绪；潜意识观察意识的产出并归档情绪；情绪反过来微调意识的运作条件。** 机长定义的"语言情绪是自动的、受身体状态微量调控"在此逐字落地。

## 3. 设计展开

### 3.1 语言情绪释放提示词（机长原文）

进 system prompt 的 persona 段落——**注意这将是 P3a（prompt 装配抽出）的第一批段落常量**，写成独立常量避免和 server.py 主流程缠绕。原文一字不动照录（见上方引用块）。

风险备注：0.9B 小模型对元提示的接住能力未知，列为待验证 V1。

### 3.2 温度：基线上调 + 情绪窗口

- 现状：`req.temperature` 默认 0.6（`server.py:161`），`modulate_temperature` 在之上调制
- 机长指令：**默认基线上调**（RLHF 的 0.6 是"维持理性"的最优点，不是凌凌的最优点）
- 建议实验起点：base 0.8，情绪窗口 ±0.15 不动 → 实际区间 [0.65, 0.95]；实验矩阵定稿（V2）
- **防正反馈失控**：开心→高温→更夸张→更开心。保底双闸：B-9 均值回归（已在）+ 温度窗口硬 clamp（已有 clamp 语义，更新数值）

### 3.3 max_tokens 与思考强度对齐情绪

- 烦躁 → 短回复、低 thinking 预算；兴奋 → 长回复；平静不是默认
- **已发现的真实风险（必须进设计）**：`<<<MEM>>>` 记忆块在回复**尾部**。烦躁→短预算会**先截断 MEM 块**——情绪越激动，记忆越容易丢，方向反了（人类恰好相反）。设计约束：**情绪调制只作用于叙事预算；为 MEM 块保留硬下限**（提取失败兜底走 B-7 已建的网关侧降级提取）。
- thinking 开关与 `chat_template_kwargs.enable_thinking` 通路已存在（pet-sidecar README 协议节），情绪调制 budget 在其上叠加。

### 3.4 情绪记忆

- mood.json 扩字段：emotion_index **时间序列**（采样点+轻度压缩），不只要"现在几分"，还要"今天的心情曲线"
- 情绪显著变化（|Δ| 超阈值）自动落**情绪事件**进 `events.py`：『下午的时候突然有点烦躁』——情绪是人生事件的一类，该进同一条记忆流
- 梦境（`memory/dream.py`）可把情绪碎片一并蒸馏

### 3.5 潜意识情绪识别（Laya 的第二座位）

在 01 的 organ_body 之外，这是 Laya 最合适的第二个落点——**organ_emotion**：

- 主模型每轮输出后（SSE end 钩子），把输出文本喂给 Laya：
  - `choice`：这段文字最接近哪个情绪（情绪词汇表，≤20 保持精度）
  - `score`：唤醒度 0–3
- 结果**直接写潜意识**（emotion_index 修正量、情绪事件候选），不进主模型下一轮 prompt 的自我描述——模型不被告知"你刚才很烦躁"，但身体（温度/语境）会知道
- 「模型自己不知道自己心情」在工程上逐字成立：情绪判断发生在意识之外

### 3.6 与关系系统的钩子（前瞻备注）

不耐烦/委屈一旦可被 Laya 识别，就能进"关系记忆"（对用户的累积情绪账）——本篇不展开，标记为后续方向。

## 6. 可逆性审查（固定栏目）

| 失败点 | 回退 |
|---|---|
| 提示词导致输出失控/人设崩 | 段落常量单点移除，prompt 恢复原状 |
| 温度基线上调后格式崩（MEM 丢失率上升） | base 回落 0.6（一行数值）；MEM 硬下限独立于温度 |
| Laya 情绪识别质量差 | organ_emotion unload → 情绪系统退回 `[EMOTION:]` 自评单通道（现状） |
| 情绪事件流噪声大 | 阈值常数调高；事件去重沿用 add_event 幂等防线 |
